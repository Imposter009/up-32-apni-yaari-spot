# Local music folder

Drop your `.mp3` files here. The player checks for a local file first; if it is missing, it falls back to YouTube.

## Folder layout

```
music/
├── chai-baatein/
│   ├── chaiyya-chaiyya.mp3
│   ├── chehra-kya-dekhte-ho.mp3

│   ├── roobaroo.mp3
│   └── gulabi-aankhen.mp3
├── lucknow-shaam/
│   ├── lag-ja-gale.mp3
│   ├── kabhi-kabhi-mere-dil-mein.mp3
│   ├── chaudhvin-ka-chand.mp3
```

Only upload music you have the rights to use.
